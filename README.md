# Engineering Portfolio — Zephram Kazimer

A responsive static engineering portfolio, built with HTML, CSS, and JavaScript. Includes original drawings and the full ME 382 Homework 7 PDF.

## Publish with GitHub Pages

1. Create a public GitHub repository, for example `engineering-portfolio`.
2. Upload **the contents of this folder** (`index.html`, `styles.css`, `script.js`, and `assets/`) to the repository root. Do not upload only the ZIP.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, and click **Save**.
5. Your site will be available at `https://YOUR-USERNAME.github.io/engineering-portfolio/` once deployment finishes.

## Customize

- Edit `index.html` to change the biography, contact details, and project text.
- Add more project cards and image files under `assets/`.
- Edit `styles.css` to adjust colors and typography.
- The included PDF is located at `assets/ME382-Homework-7.pdf`.

No backend, build tools, or dependencies are required. Google Fonts is optional; the site has system font fallbacks.

## Source and accuracy

Project information, technical drawings, and analytical values come from the uploaded *ME 382: Homework 7* report (November 15, 2026). Estimates are presented as preliminary calculations, not experimentally verified outcomes. Contact information is deliberately left unfilled rather than invented.
